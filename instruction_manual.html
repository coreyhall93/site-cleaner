Site Cleaner Instruction Manual

Use this process to clear a WordPress test or staging domain after the finished client site has already been moved to production with All-in-One WP Migration.

Plugin: Site Cleaner 0.3.0 Platform: WordPress Updated: May 28, 2026

Overview

Site Cleaner clears old client-build content from a test domain while leaving the WordPress install and user accounts in place. It is meant for test and staging sites, not production websites.

The plugin uses a guided wizard, a dry run, and a final confirmation phrase so the person running it can see what will happen before anything is deleted.

Use this only after production is done

The finished website should already be moved to the production domain and checked before you clean the test domain.

Before You Begin

Make sure you have:

  • The test or staging domain name.
  • The production domain name.
  • Direct WordPress admin access for the test site.
  • Confirmation that the production site was moved with All-in-One WP Migration.
  • Confirmation that production has been checked and no longer needs anything from the test site.
Use direct WordPress login

Log into the test site directly with /wp-admin. Check the browser address bar before running the wizard so you do not clean the production site by mistake.

Step 1

Install Site Cleaner

  1. Log into the test or staging WordPress admin directly.
  2. Confirm the browser address bar shows the test domain.
  3. Go to Plugins -> Add New -> Upload Plugin.
  4. Upload site-cleaner.zip.
  5. Activate Site Cleaner.
  6. Go to Tools -> Site Cleaner.
Step 2

Walk Through The Wizard

  1. Confirm you are logged into the test or staging domain.
  2. Confirm the finished site has already been moved to production.
  3. Review the content cleanup options.
  4. Review the site title, ready screen title, and ready screen message.
  5. Review the plugin and theme deletion lists.
  6. Uncheck anything the test site should keep.
Plugin and theme defaults are aggressive

Most non-protected plugins and themes are checked for deletion by default, including migration/build plugins. Site Cleaner, ManageWP Worker, network-active plugins, and Twenty Twenty-Five are protected.

Step 3

Run The Dry Run

  1. Click Run dry run.
  2. Read the output list.
  3. Confirm the list matches what you expect to remove.
  4. If something should stay, scroll back up, uncheck it, and run the dry run again.

The dry run does not change the site.

Step 4

Run The Final Clean

Only continue when the dry run looks right

The final clean permanently deletes the selected content, plugins, and themes.

  1. Check both confirmation boxes at the top of the wizard.
  2. Type CLEAN TEST SITE exactly.
  3. Click Clean test site.
  4. Wait for the result list to finish.
Step 5

Check The Test Site

  1. Open the test domain in a browser.
  2. Confirm the old client site is gone.
  3. Confirm the ready screen appears.
  4. Log back into WordPress admin.
  5. Check Pages, Posts, and Media.
  6. Check Plugins and Themes.
  7. If the test domain is tracked in ManageWP, confirm ManageWP opens the test domain's WordPress admin.

Quick Checklist

  • Production site has already been moved and checked.
  • You are logged into the test or staging WordPress admin.
  • site-cleaner.zip is uploaded and active.
  • The wizard confirmations are checked.
  • The dry run output has been reviewed.
  • The final phrase CLEAN TEST SITE is typed exactly.
  • The old client build is gone from the test domain.
  • ManageWP opens the correct test-domain admin, if used.

Protected Items

Site Cleaner will not delete:

  • WordPress users.
  • Site Cleaner.
  • ManageWP Worker.
  • Network-active plugins.
  • Twenty Twenty-Five.
  • Any plugin or theme you uncheck before the final clean.

ManageWP Notes

ManageWP usually should not need to be reconnected after Site Cleaner runs. The plugin protects ManageWP Worker and keeps WordPress in place.

If ManageWP opens the wrong site

  1. Stop using ManageWP one-click login for that site.
  2. Log into the test site directly through /wp-admin.
  3. Confirm ManageWP Worker is installed and active.
  4. Confirm the saved ManageWP URL is the test domain.
  5. Reconnect the test domain only if ManageWP still cannot sync or open the correct WordPress admin.

Important Reminders

  • Always verify the browser address bar before making changes.
  • Always run the dry run first.
  • Never run the final clean on production.
  • When unsure, uncheck the plugin or theme before continuing.
  • When the dry run looks wrong, stop and fix the selections.
